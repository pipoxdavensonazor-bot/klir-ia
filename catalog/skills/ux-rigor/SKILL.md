# UX Rigor — Klir IA

## Checklist WCAG (sites générés)

- Contraste texte ≥ 4.5:1 (AA) ; CTA ≥ 3:1 sur fond
- Focus visible sur liens/boutons
- Labels sur inputs ; `aria-label` si icône seule
- Hiérarchie headings : un seul H1
- Pas d'info uniquement par couleur

## Responsive

Mobile-first · breakpoints 768 / 1024 · pas de scroll horizontal · images max-width 100%

## Motion

Durées 150–300ms · respect `prefers-reduced-motion: reduce`
