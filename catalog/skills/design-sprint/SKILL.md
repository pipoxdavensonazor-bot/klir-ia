# Design Sprint — Klir IA

## 5 phases (condensées)

1. **Understand** — problème, utilisateur, métrique succès
2. **Sketch** — 3 directions layout (texte/wireframe)
3. **Decide** — une direction + pourquoi
4. **Prototype** — HTML/CSS ou spec sections
5. **Test** — 3 questions utilisateur + ajustements

## Pour Studio Klir IA

Avant génération : valider type site, objectif, sections — puis une direction esthétique unique.
