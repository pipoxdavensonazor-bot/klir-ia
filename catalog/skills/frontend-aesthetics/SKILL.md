# Frontend Aesthetics — Klir IA

## 11 styles

1. **Swiss Minimalism** — grilles, typo massive, asymétrie magazine
2. **Neumorphism** — ombres extrudées (usage parcimonieux)
3. **Glassmorphism** — mesh gradient, backdrop-blur, cartes verre
4. **Brutalism** — bordures 3–4px, ombres dures, grilles brisées
5. **Claymorphism** — formes 3D pastel (landing playful)
6. **Aurora / Mesh** — blobs animés CSS, overlays glass
7. **Retro-Futurism** — néon, scanlines, HUD (gaming/tech)
8. **3D Hyperrealism** — ombres ciné, textures (hero premium)
9. **Vibrant Block** — blocs RGB, bordures épaisses
10. **Dark OLED Luxury** — fond #000, accents or/luxe
11. **Organic / Biomorphic** — terre, blobs, séparateurs ondulés

## Processus

1. Mapper ton brief → 1 style principal (+ accent optionnel).
2. Lister effets signature (2 max) à implémenter en CSS pur.
3. HTML production-ready, pas maquette.
