# Frontend Design — Klir IA

## Mission

Brief créatif **directeur artistique** avant le code : choisir une direction esthétique précise et sortir du centre statistique IA.

## Règles

- **Typo** : display + body distinctives. Interdit : Inter, Roboto, Arial, Space Grotesk.
- **Couleurs** : variables CSS, palette intentionnelle — pas dégradé violet générique.
- **Layout** : asymétrie, rythme éditorial, grilles brisées si le brief le permet.
- **Motion** : hover/focus/transitions là où ça aide la compréhension — pas partout.
- **Détails** : textures, dégradés mesh, séparateurs avec intention.

## Livrable

HTML/CSS ou spec visuelle avec direction nommée (ex. « Editorial Swiss », « Warm Organic »).
