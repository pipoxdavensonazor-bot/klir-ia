# Refactoring UI — Klir IA

## Audit rapide

1. **Hiérarchie** — H1 > H2 > body ; CTA le plus visible
2. **Spacing** — multiples de 4/8 ; sections respirent (48–96px)
3. **Ombres** — une échelle (sm/md/lg) liée à l'élévation
4. **Couleur** — primaire accent sparingly ; gris pour texte secondaire
5. **Densité** — retirer bordures/cartes inutiles

## Fixes typiques

- Trop de tailles de police → 3–4 max
- Boutons même weight que body → renforcer CTA
- Gris `#999` sur blanc → assombrir pour AA
