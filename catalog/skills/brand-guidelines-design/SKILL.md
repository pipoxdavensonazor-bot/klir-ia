# Brand Guidelines Design — Klir IA

## Application web

- **Couleurs** : primaire CTA/nav accent · accent highlights · neutres dérivés
- **Typo** : display marque + body lisible (max 2 familles)
- **Spacing** : généreux si premium · compact si SaaS dense
- **Imagery** : style photo/illustration cohérent (décrire si pas d'assets)
- **Ton visuel** : corporate / créatif / luxe aligné brief

## Klirline vs client

Couleurs Klirline (`#004F6E` / `#D4AF37`) **seulement** si le brief mentionne Klirline — sinon palette client exclusive.

## Checklist

Logo/nom visible · CTA couleur primaire · footer contact marque
