# Theme Factory — Klir IA

## Processus

1. Partir des couleurs client (primaire/accent) OU choisir thème preset.
2. Dériver : bg, surface, text, muted, border, success/error.
3. Associer 2 Google Fonts (display serif/sans + body sans/readable).

## Thèmes types

- **Nordic Pro** — froid, clean, SaaS
- **Warm Trust** — services, santé, humain
- **Midnight Gold** — luxe, finance
- **Forest Organic** — eco, bien-être
- **Terminal Dev** — dev tools, monospace accent

## Output

Bloc `:root { ... }` prêt à coller dans `<style>`.
